# 隐私政策（Agent 工坊）

> **生效版本**：v3.7.104（2026-10-10）
> **适用形态**：网页版 / PWA / Electron 桌面版（三者共用同一份 `agent-workbench.html`，数据处理行为一致）

> ⚠ **文档性质声明**：本文是对本应用**实际数据处理行为**的如实描述，不是法律意见，
> 也不构成任何合规认证。正式对外发布前须由法务/合规人员结合适用法域（如《个人信息保护法》）审核。
> 文中所有「不收集 / 不上报」的表述均可由本仓库源码验证（见 §五 自证方式）。

## 一、一句话结论

**本应用是本地优先（local-first）应用：你的任务、资料、笔记默认只存在你自己的设备上，
不上传、不共享、不含遥测与行为统计。** 只有你主动启用的功能才会产生网络请求。

---

## 二、数据存在哪里

| 数据类别 | 存储位置 | 是否离开设备 |
|---|---|---|
| 任务 / 资料 / 笔记 / 习惯链 / 仪表盘布局 | 浏览器 localStorage（同步真相源）+ IndexedDB（异步镜像） | ❌ 否 |
| 自动备份（三代滚动） | 同上，本地 | ❌ 否 |
| 回收站 | 同上，本地 | ❌ 否 |
| AI 模型密钥（Key） | 本地存储，`AES-GCM` 加密 | ❌ 否（调用时直达服务商） |
| 飞书 / 钉钉 / Slack 的 webhook 地址与密钥 | **仅内存**，不写盘、不进备份、不进云同步，刷新即失效 | ❌ 否 |
| Notion / Linear / Jira 的连接凭据 | 本地密封存储（`wb_integration_providers`），**不纳入备份** | ❌ 否 |
| 账号与云同步（可选） | 需**另行部署的后端服务**；不部署则完全不启用 | 仅当你主动部署并启用 |
| 桌面萌宠 | 纯本地 UI 状态 | ❌ 否，且不接入 AI、不读取用户数据 |

**存储上限**：浏览器本地存储硬上限约 5 MB（应用内「设置 → 存储用量」可实时查看占用与 Top 5 条目）。
自动备份受单条 1.5 MB / 三代合计 4 MB 的内部护栏约束。

**数据安全边界（如实告知）**：
- 数据损坏时应用会保留原始内容副本并提示，**不会静默丢弃**；
- 受 5 MB 上限约束，备份会占用其中相当部分；
- 若浏览器禁用了本地存储（隐私模式等），应用会退化为内存态，**关闭即丢失**。

## 三、什么时候会产生网络请求

**默认状态（未配置任何服务）下，本应用不产生任何外部网络请求 —— 唯一例外是首次加载
代码执行 / SQL 运行时（WASM）时可能从公共 CDN 拉取运行时文件。**

以下功能**仅在用户主动配置并启用后**才联网：

| 功能 | 请求去向 | 说明 |
|---|---|---|
| AI 助手 / Agent / 语义检索 | 用户自填的模型服务商 | 需用户自备 Key；请求直达该服务商，本应用不做中转 |
| 联网检索 | 对应的检索服务 | 同上 |
| 集成（Notion / Linear / Jira / 本地日历） | 对应平台 API | 未连接即零外发 |
| 群机器人通知（飞书 / 钉钉 / Slack） | 对应 webhook 主机白名单 | 桌面形态下经主进程代发；日志**只记主机与状态码**，不记密钥与正文 |
| ICS 日历订阅 | 用户自填的订阅链接 | 桌面形态下经主进程只读中继：拒私网/回环地址、≤2 MB、不带认证头 |
| WebDAV 云同步 | 用户自填的服务（如坚果云） | 应用密码加密落盘，ETag 冲突检测，冲突时弹确认**不静默覆盖** |
| 账号 / 云同步 | 需另行部署的后端 | 仓库不含可用的托管后端；未部署时 UI 会如实提示「未检测到账号服务」 |

## 四、我们不做什么

- **不做遥测、埋点、行为统计**：源码中不存在任何分析/上报通道（可 grep 验证，见 §五）。
- **不做广告，不出售数据**：本应用无广告 SDK，也不存在任何数据对外共享或交易通路。
- **不设隐性账号**：不注册也能完整使用本地任务、资料、导入导出等核心功能。
- **不静默覆盖**：云同步遇到版本冲突会弹窗确认，不会自行用远端覆盖本地。

本文所有实质主张都可由本仓库源码复核，不依赖信任：

```bash

grep -n "AUTO_BACKUP_GENS\|AUTO_BACKUP_MAX_BYTES\|IDB_MIRROR_PREFIXES" src/*.js

# 3. 确认集成 webhook 凭据不落盘
grep -n "notifyHookConnect" src/ui-ge-integrations.js   # 凭据仅存模块内存对象
```

## 六、用户对自己数据的控制

- **导出**：设置 → 数据管理 → 导出（含任务、资料与自定义链接）。
- **导入**：支持导入既有备份；应用会提示过滤口径。
- **清除**：清除浏览器站点数据即彻底删除本地一切内容（含备份与回收站）。
- **备份管理**：三代滚动自动备份可查看与回滚。
