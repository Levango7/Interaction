## 1. 定位

- **一句话**：把工作台从「左导航 + 主视图 + 右栏 + 底部对话坞」重排为 IDE 化单栏流 —— 顶栏菜单行 + 场景 tab 条、左栏（快捷操作 + 工作区列表 + 工具）、面包屑主区、底部 Composer（对话坞新家）、右栏分节（今日任务轨为首节）、底部状态栏。
- **用户与价值**（对齐 `docs/PRODUCT.md` 北极星「每周完成闭环用户数」）：场景切换（tab）、AI 输入（底部 Composer）、今日焦点（右栏任务轨）三者常驻可见，缩短「捕获 → AI 落手 → 复核 → 沉淀」路径；IDE 化心智服务跨场景（code/work/design）功率用户。
- **反目标**：不是 B · Chat-first 沉浸（与已定稿「右栏今日任务轨 ≥1024 常驻 280px」直接冲突，已裁掉）；不引入编辑器/终端/真文件树（零新依赖，单文件架构不变）；菜单栏是应用内轻菜单（视图切换/帮助/快捷键），不复刻原生 OS 菜单。

## 2. 与定稿约束逐条 reconciliation（硬约束，不可违）

| 定稿约束 | 形态 A 下的落地 |
|---|---|
| 对话坞默认收起 | 对话坞迁为底部 Composer：**单行输入条即收起态**；聚焦/点展开向上长成对话面板（默认 40vh 可拖高，沿用 10-21 定稿的两档语义） |
| 右栏今日任务轨 | 右栏**第一节**即今日任务轨（逾期→今天→有日期→无日期 ≤8 条，只看和勾）；其下叠产出清单等分节 |
| 沉浸页隐藏坞 | 沉浸页隐藏 Composer + tab 条，留面包屑 + 主区 |
| 断点以 lint-breakpoints 允许集为准 | 复用 1023/767/479 三档，**不新增断点值**：≥1024 右栏常驻 280px；768–1023 右栏滑出；≤767 左栏抽屉 + Composer 单行 |
| pill 模式开关（#134 已交付） | 移至 tab 条左（模式=全局、场景=每 tab，同行异义）；模式语义/三态循环/窄屏拒 code 判据不变 |

## 3. 与现状的 delta + 诚实爆炸半径

- **加**：菜单栏行、场景 tab 条、面包屑栏、底部 Composer（对话坞迁移）、状态栏。
- **移**：对话内容 → Composer 展开面板；场景入口 → tab 条 + 左栏入口并存。
- **留**：四区导航（左栏）、右栏任务轨、全部视图注册表与 data-action 绑定（ARCHITECTURE 契约）、#134 窄屏判据。
- **爆炸半径**：`agent-workbench.html` 骨架 CSS；`src/render-widgets.js` / `src/render-overview.js` 右栏分节与坞迁移；draw-responsive 15 例 e2e 需按新宽度构成复测（主区宽度构成变化）。
