## OD-002 缺陷详述

**现象**：登录弹窗切到微信扫码 → 显示一张写着「微信登录（演示）/ 未配置微信 appid / scene: wx_xxx」的 SVG，
下方提示「打开微信「扫一扫」完成登录」→ 客户端每 2.5s 轮询 `/wechat/status` → **永远 pending**，
5 分钟后报「二维码已过期，请关闭后重新扫码」。用户视角：功能看起来能用，实际是死循环。

**证据**：
- `server/src/auth.js:313` `return ok(res, { qr: ..., scene, expireIn, demo: true });`
- `server/src/auth.js:307-309` 注释：「演示码必须让调用方消费端看得出是演示（demo:true），不能伪装成真二维码」
- `src/render-overview.js:1190-1196` 只判 `if(qr)`，`d.demo` **未被读取**

**严重度**：P1（非安全缺陷——无认证绕过；但为用户可见的功能不可用 + 误导性文案）。
