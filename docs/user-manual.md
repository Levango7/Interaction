## 1. 这是个什么东西

一个跑在你设备上的个人任务工坊：任务、资料、笔记、记忆都在本机浏览器里，
AI 助手可以直接替你增删改查这些数据，而不是只会聊天。

三句话概括它的性格：

- **本地优先**。不登录、不配任何服务，全部核心功能可用；数据在你自己的浏览器里。
- **能力如实**。界面上能看到的功能都是真接线了的；做不到的会直接说做不到，
  不会给一个能点但没反应的按钮。
- **AI 能上手**。AI 助手带 26 个工具，动的是和你手动操作同一份数据；另有 7 个
  agent 工具负责记忆、多步目标、跨场景协调。

## 2. 三种用法与安装

| 形态 | 适合谁 | 注意事项 |
|---|---|---|
| 浏览器 / PWA | 大多数人 | 用 Edge/Chrome 打开页面，地址栏可「安装应用」，装后可离线用 |
| 本地服务 | 想把地址固定下来的人 | `npm run serve` 后开本地静态服务 |
| Electron 桌面版 | 想要独立窗口与托盘的人 | 桌面版才有「主进程代发」类能力（WebDAV 等跨域抓取）；安装包从 Release 取 |

**升级**：PWA 会在更新后首次打开时提示「新版本已就绪」，点击即刷新；
页脚显示 `v3.7.x · b{构建标记}`，看不到构建标记说明还在旧缓存，Ctrl+Shift+R 强刷。

## 3. 界面骨架

**左侧导航共 17 项**（2026-10-12 真机取证，含数字角标的是该场景待办数）：

| 分组 | 入口 |
|---|---|
| 主区 | 主页 / 任务 / 场景联动 / 时间轴 |
| 7 个场景 | 办公 / 数据 / 设计 / 学习 / 编程 / 生活 / 健康 |
| 功能区 | AI / 工具箱 / 商店 / 回收站 |
| 系统区 | 设置 / 说明 |

每个场景三类内容：任务看板、资料库、场景工具。其中「任务」是**跨场景总看板**
（看板 / 日历两个视图）；「商店」就是插件市场，是**侧栏独立入口，不在设置抽屉里**。

**顶栏**（左→右）：帮助（使用指南）/ 搜索 / 命令（命令面板）/ 消息 / 主题切换 /
下载 / 安装应用（PWA）/ 登录（未登录时显示「登录」）。

**顶栏下方待办栏**：显示「今天 N 件待处理 · 已完成 N 件 · 联动 N 条进行中」，可展开收起。
**右侧聊天面板**：AI 对话区，含会话管理、模型选择、文本附件。
**窄屏时**侧栏自动收成底部 Tab。

**命令面板**（`Ctrl/Cmd+K` 或顶栏「命令」）：分组为 命令 / 场景 / 任务 / 工具（另有技能组），
可快速跳转与执行命令；`>` 前缀是「让 AI 自主完成一段任务」的入口（详见 §7）。

## 4. 任务与资料

- **任务**：每个场景一个看板，三列状态（待办 / 进行中 / 已完成）。支持优先级、
  截止日期、标签；删除先进回收站，不是立即消失。
- **资料**：按场景分的记录（会议纪要、作品记录、学习资料、数据记录、代码片段、
  生活记录、健康记录），是任务之外的「过程沉淀」。
- **习惯链**：跨场景联动（例如「编程完成 → 健康记录饮水」），有 streak 与热力图。
- **时间轴**：14 天 × 场景泳道的任务回放，看你这段时间在各场景投了多少。
- **仪表盘与报表**：仪表盘 15 个可拖拽组件；报表按周 / 月 / 年汇总与对比。
- **场景工具**：学习场景的 SM-2 间隔复习、办公/编程场景的周报生成器、
  数据场景的 SQL Playground（本机 WASM 内存库，不连你的真实数据库）。

## 5. AI 助手

### 5.1 先配置才能用

设置 → AI：填 API 基址、Key、模型。Key 用设备密钥（AES-GCM）加密后存在本机，
**设备密钥不出本机**——所以换了设备/浏览器，Key 不会跟过去，需要重填。
不填 Key 也能用应用的其余全部功能。

### 5.2 它到底能动什么

26 个工具分三档，前两档是「对数据的增删改查」，第三档需要联网或本机计算：

- 任务 / 资料 / 记忆：创建、修改、完成、删除、查询。
- 学习与健康：复习卡调度、记录写入。
- 联网与计算：`web_search`（联网检索）、`web_fetch`（抓网页正文）、
  `code_run`（浏览器内 JS 沙箱）、`sql_query`（本机 WASM SQLite）。

其中 `delete_task` / `update_task` 是**危险操作**：AI 发起时一定弹窗要你确认，
不会静默改你的数据。其他工具直接执行。

### 5.3 用得稳的几条经验

- **目标说清楚**。AI 定位任务靠标题关键词，重名时取第一条——名字起得具体，它就不会找错。
- **破坏性指令让它先说**。比如「把这些任务删掉」，它会先列再确认，比直接说「删」更稳。
- **断网/超时会如实报错**，不会假装成功；报错后可以点重试，也可以改模型参数再重试。
- **上下文有预算**（默认约 1200 token，可调）。它每轮只带「最近的对话 + 注入的记忆/技能/RAG」，
  不是无限记忆——重要的事让它「记住」，不要指望它自己记得很久以前的对话。
- **长对话会自动折叠**（v3.7.118 起）：会话超过约 40 条后，更早的内容会被折成一段摘要
  （一次额外请求），之后每轮只发「摘要 + 最近约 20 条」——token 成本不再随聊天轮数一直涨。
  三条保证：折叠只影响**发送时发什么**，你本机的聊天记录原样不动（诊断报告的「上下文摘要」
  一行能看到折叠了几条）；摘要请求失败时自动回退成全量发送，不会因此报错；摘要按会话存放，
  新会话不会带上旧会话的摘要。想关掉：设置 → AI → 关闭「长对话摘要」（或把触发条数调大）。

## 6. 记忆、知识库与上下文预算

三种东西，别混淆：

| 形态 | 是什么 | 谁触发写入 | 上限 |
|---|---|---|---|
| 工作记忆 | 你或 AI 主动记下的事实、偏好 | 「记住：xxx」或 AI 的 remember 工具 | 默认 60 条（20~500 可调），超了留最近的 |
| 知识库（笔记/RAG） | 笔记、导入的文本，按段落切块建索引 | 你写笔记/导入文件；数据变更后自动增量索引 | 文件知识源 60 个文件 |
| 会话历史 | 当前对话本身 | 每轮对话 | 50 条 + 约 6000 token，超出自动裁剪最旧的 |

**什么时候会召回**：每次你发消息前，应用会把「相关记忆（最多 6 条）+ 相关 RAG 片段
（最多 8 段）+ 匹配的技能」按预算塞进提示词。命中过的记忆会被标热，但**不会自动淘汰**——
你认为过时了，用「忘记」让它删。

**语义检索可能悄悄降级**：语义向量依赖两件事——可用的 embedding 通道和 IndexedDB。
任一不可用时它会自动退回纯词法检索（搜索结果变糙）。**诊断面板会告诉你**：
「设置 → 关于 → 诊断与反馈」的报告里有一行「语义召回」——「向量检索可用」或
「词法降级 — embedding 通道不可用 / IndexedDB 不可用 / 未配置」。看到降级不用手动修，
按行里的原因处理（配好嵌入通道、退出隐私模式），10 分钟内会自动重试。

## 7. 目标与自主执行

产品里有两套「多步任务」，用途不同；从 v3.7.117 起它们**共用同一份目标存储**——不管从哪个入口发起，「进行中目标」在对话里的提示（含「请继续执行第 N 步」）都指同一件事：

- **目标（plan）**：在对话里让 AI 建一个带步骤的目标。步骤落盘（刷新不丢），每轮对话把未完成的步骤重新读进来——**但需要你再说一句话才会推进下一步**。适合「这事我盯着，让它分步做」。
- **自主执行（`>` 命令面板）**：输入 `> 把这三篇文章整理成摘要`，AI 先给计划、你评审确认，然后它分段执行（每 3 步一次，最多 12 步，可重规划两次）。**评审态与执行进度都落盘**：确认后刷新页面，下次打开会提示「有一个未完成的执行（第 N/共 M 步）」，发「继续执行」就从下一步接着跑（已完成的步骤不会重跑），发「放弃执行」连记录一起清。适合「一次性、可评审、短流程」的活。

两套入口共用单目标存储：新目标会顶替旧的进行中目标（同时只有一个「进行中」）。
长任务的诚实边界：**没有跨设备续跑**（执行状态只在本机）——如果你在别台设备登录同一账号，那边的执行状态不会跟过来。

## 8. 日历

走的是**零凭据 ICS 路线**：本地导入 `.ics` 文件，或订阅公开只读的 ICS 链接
（QQ 邮箱、网易、Outlook 等都能导出订阅链接，国内直连）。

- 外部日程与本地任务/会议在日历视图里分色分列。
- 订阅源可重命名、可单独启用停用；解析失败会按行给诊断（哪一行、什么原因）。
- 也可以把本地任务/会议导出成 `.ics` 给别人。
- **不支持**：Google/Outlook 的 OAuth 双向同步（需要能连 googleapis，且个人配不通）；
  华为 HMS 日历（那是 Android 原生 SDK，与 Web 交付形态不兼容）。

## 9. 集成与 WebDAV

设置 → 集成里可以连多家第三方。**先说清楚的边界**：这些连接的用途是
「验证凭据 + 单向推送」——它们**不会**自动把你的任务同步进 Notion、也不会自动拉 Slack 消息进来。
界面文案只承诺验证，不承诺同步，这是刻意的。

- **WebDAV（坚果云等国内网盘）**：标准 WebDAV + 应用密码，可以真的做云快照备份
  （上传/下载快照，带 ETag 冲突检测，冲突时弹窗让你选「用云端覆盖 / 放弃」）。
  注意桌面版走主进程代发，浏览器版受 CORS 限制可能连不上。
- **Linear/Jira**：连接后可拉真实工作流状态，推送任务时带上远端状态 ID。
- **飞书/钉钉/Slack**：Webhook 通知（凭据只存会话内存，不落盘）。

## 10. 账号与云同步

**默认不启用也可以正常用全部功能。** 只有想多设备同步时才需要：

1. 部署后端（仓库 `server/` 目录，Express，需要 Node 环境）。
2. 设置 → 账号：填 API 基址、注册或登录邮箱账号。
3. 「立即上传」把本机数据推成云端快照；另一台设备登录同账号后
  点「恢复云端」拉下来（拉取前会自动留一份本机回滚档）。
4. 快照**只含业务数据**：AI Key 密文、设备密钥、同步元数据都不上云
   （密钥出了本机也没意义，纯增暴露面）。

未部署后端时，界面会如实告诉你「未检测到账号服务」，不会假装同步成功。

## 11. 数据安全

- **自动备份**：按策略保留最近几代，自动备份同样不上云、不跨设备。
- **导出/导入**：全量 JSON 导出；导入前建议先导出一份（导入是替换语义）。
- **回收站**：删错的东西先去回收站找，超过保留期才真删。
- **同步冲突**：同一 key 两边都改过时——任务类会自动按 id 合并（新的赢），
  其他 key 让你选「保留本机 / 使用云端」，不静默覆盖。

## 12. 主题、萌宠与个性化

- 主题：亮/暗/跟随系统，外加护眼、黑金等预设主题；跟随系统会实时切换。
- 桌面萌宠：9 个角色、两档风格、三档尺寸，纯本地 UI 陪伴，**不读你的数据、不接 AI**。
- 插件市场：番茄钟、阅读、理财、预算等可开关。诚实说明：多数插件启用后是
  通用任务骨架，只有阅读插件接了额外能力——想要的功能没有时它会说没有。

## 13. 出问题时先看这里

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 登录后提示成功但实际没登录 | 后端与客户端版本不匹配 | 升级到 v3.7.112 之后的版本 |
| GitHub/微信登录提示无法使用 | 后端没配 OAuth，或微信是企业资质项 | 邮箱登录不受影响；GitHub 配好 OAuth App 即可 |
| 同步显示「仅本机」 | 没配后端或后端没启动 | 设置里填对 API 基址 |
| AI 回复「无法连接 API」 | Key/基址/网络 | 看设置里的 AI 配置；超时可调大 |
| 语义搜索找不到内容 | embedding 通道或 IndexedDB 不可用，已降级为词法检索 | 开「设置 → 关于 → 诊断与反馈」看**语义召回**那一行：写着「词法降级」就是它；按行里给的原因处理（配好 AI 的嵌入通道 / 别用隐私模式）。恢复后无需手动操作，10 分钟内自动重试 |
| 刷新后丢失了刚记的内容 | 用了隐私模式/存储被清理 | 正常模式下使用；重要数据定期导出 |
| 页面卡在旧版本 | Service Worker 缓存 | 页脚看不到构建标记时 Ctrl+Shift+R |

## 14. 常见疑问

**不登录数据存在哪？** 本机浏览器 localStorage，另有 IndexedDB 镜像。
清浏览器数据会一起没，所以重要数据请定期导出。

**能不能完全离线？** 能。AI 助手、账号同步、日历订阅、WebDAV 是仅有的几个
需要网络的点；其余功能全离线可用。

**数据会上传到哪去？** 只有你显式配置的后端（自建）和你自己填的第三方
（WebDAV/集成）。除此之外没有任何上传——应用没有内置 Analytics、没有遥测。

**换设备了怎么办？** 导出 JSON，在新设备导入；Key 需要重填（密钥不出本机）；
开了云同步的话直接登录同账号拉云端快照。
