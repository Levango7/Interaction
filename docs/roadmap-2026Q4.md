## 三、质量基线（守门不退让）

- 任何版本发布前：串行全量单测 → e2e → 六门禁 → **CI 独有门禁**（lint:tokens 等本地不含的，
  v3.7.84 的悬空令牌就是 CI 抓出来的）→ 线上指纹复核 → 台账记账。
- 分层纪律：新代码不许新增跨层逆层边；需要就开 AppBridge 槽位（core 留位、高层注册）。
