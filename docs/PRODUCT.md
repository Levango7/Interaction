# PRODUCT.md · 产品定位与取舍（活文档）

> 状态：**活文档（2026-10-20 建立，2026-11-07 三模式改写）**。本文件是"要不要做某个功能"的**唯一裁决依据**。
> 分工：`docs/product-scope.md` 管**能力清单与已移除功能防回潮**，`docs/ARCHITECTURE.md` 管**分层契约**，
> `docs/DESIGN-SYSTEM.md` 管**视觉 / 断点 / 布局契约**，`docs/three-mode-spec.md` 管**三模式行为规格**，
> `docs/demand-ledger.md` 管**需求状态**（三份契约均已落盘）。本文件回答**为什么做、给谁做、不做什么**；冲突时以本文件为准，并回来改那几份。
> 判读规则见 `docs/README.md`：历史快照（roadmap / iteration-plan / evaluation-* / 半成品路线图）**只供追溯，不作为现状依据**；要看现状读代码、跑门禁。

## 1. 一句话定位

> **一个能真正动手的本地优先 Agent 工作台**：同一份数据、同一套能力，按你当下在干什么，切成
> **Work / Code / Design** 三种摆法；AI 不是聊天框，是能改数据、跑工具、派子代理、画图的执行者。

四条必须同时成立，缺一条就不是这个产品：

1. **单文件交付**：可离线、可拷走、可归档，无安装、无账号；源码态 HTML + 注入态构建产物，仍是同一份交付。
2. **本地优先**：默认不联网；联网是一次显式选择，不是前提。可选账号 / 云同步依赖可自建后端，不登录时全部本地功能可用。
3. **AI 落手**：能读你的数据、改你的数据、替你推进任务。当前是 **29 个 function-calling 工具** + 计划-执行 + 子代理编排 + 技能 + MCP + 画图产物，而不是只回话。
4. **模式是布局预设，不是能力开关**（2026-11-07 新增公理）：三模式**共用同一份数据、同一套工具、同一套撤销与权限**。模式只改变「什么摆在你面前」，不改变「你能做什么」。任何"只在某模式可见才可用"的新能力，一律不做。

   > **「产物域」口径澄清（2026-11-08，裁决方 = 本文件）**：`442483c` 起空对话快捷指令与聊天区提示随模式切换，
   > `CHANGELOG.md` 将其表述为「三模式成为『产物域』而非纯布局预设」。此处定性：**产物域 = 空态提示词与展示域的差异，
   > 不是能力门禁**。三模式仍可调用全部工具、访问全部数据、复用同一套撤销与权限。
   > 任何以「产物域」为由 gate 能力、隐藏数据或分叉权限的实现都违反本公理；
   > 反之，按模式换一批快捷指令、换一套代码块观感，属于布局预设内的呈现差异，允许。

### 三种摆法（一句话版）

| 模式 | 一句话 | 中栏是什么 |
|---|---|---|
| **Work（工作）** | 日常任务与资料，AI 随手可用 | 任务 / 看板 / 日历 / 资料库 / 笔记 + 贴底对话坞 |
| **Code（代码）** | agent-first 控制台：看会话、看进程、看能力 | 全高对话区（输入行贴底居中）+ 左会话停靠 + 右能力停靠 |
| **Design（设计）** | 画布优先：把想法和 AI 产物画清楚 | SVG 画布编辑器 + 左图列表 + 右待办轨 |

> **Code 不是 IDE，Design 不是绘图平台**。它们的命名指向「你当下在干什么」，不是「我们实现了什么软件品类」。
> 这一条是砍需求的刀，见 §3。

## 2. 用户

**主用户**：重视数据主权的独立开发者 / 研究者 / 知识工作者，且现在同时是**agent 使用者**——
会开多个会话、会看子代理跑到第几步、会给 AI 勾 MCP 工具、会把 AI 画的架构图接过来继续手改。
特征：愿意为"数据在谁手里"付出配置成本（自带模型 Key、必要时自建同步服务）；任务多、资料散、
已经在用 markdown / 笔记 / 待办工具但都不满意；能接受"配置 10 分钟，用一年"。

**明确不是我们的用户**：

- 团队 / 企业采购，需要审批流、多人权限、审计合规套件的组织；
- 纯手机轻用户、不愿配置任何 Key 的大众消费者；
- **想要 IDE 级编码体验的人**（需要文件树、编辑器、终端、调试、Git 的人，Code 模式给不了，也不打算给）；
- **想要专业绘图平台的人**（图层 / 多选 / 模板库 / 多人协作，Design 模式给不了，也不打算给）。

## 3. 反目标（写下来是为了砍需求）

- 不做团队协作、共享空间、多人权限。
- 不做企业多租户、SSO、审计合规套件。
- 不做多文件工程（单文件是产品，不是技术债）。
- 不做社交、社区、模板市场分成。
- **不做面向第三方的通用低代码 / 工作流编排平台**：内部的计划-执行器与子代理是 **AI 执行护栏**，
  不是对外开放的工作流产品；不提供编排器 UI、不对外暴露调度 API。
- **不做 IDE**：Code 模式是 agent 的运行面（会话 / 进程 / 技能 / MCP / 工作流），不是代码编辑器。
- **不做绘图平台**：Design 模式是「把想法与 AI 产物画清楚」的轻量画布，不做 draw.io / Figma 全功能集。
- **不做模式特供能力**：不为某个模式复制一份工具、数据或 CRUD；不做"这个能力只有切到 X 模式才能用"。
- 不做"什么都能集成"的集成中心；只做**能把任务送出去 / 收回来**的少数几条链路。

### 裁决三问（任何新需求先过这三关）

1. 它服务 §1 四条里的哪一条？答不出 → 进 Labs 或不做。
2. 它是**能力**还是**摆法**？能力必须三模式都可达（或书面说明为何不能），摆法才允许模式差异。
3. 它在 §4 四步闭环里是哪一步？模式切换**本身不算一步**，不得把"切模式"包装成任务。

## 4. 核心闭环（所有页面必须服务它）

**捕获 → 委派与执行 → 复核 → 沉淀 / 带走**

| 环节 | 用户动作 | 产品必须提供的 | 当前状态（2026-11-07 实测） |
|---|---|---|---|
| 捕获 | 记下一件事 / 导入一份资料 / 接到一条消息 | 3 秒内能记下：首屏主 CTA、全局快捷键、命令面板；**三模式都在** | 首屏 CTA 已有；`Ctrl/Cmd+K` 与 `>` 命令面板已有 |
| 委派与执行 | 让 AI 拆解、改期、归类、起草、跑工具、派子代理、画图 | 可见地读数据、改动可撤销、失败可解释；危险动作二次确认 | **29 个工具**已接线（`src/ai-tools.js:303-382`），含 `plan` / `spawn_agent` / `spawn_agents_parallel` / `draw_svg`；计划-执行 + 子代理 + 技能 + MCP 已成真能力；**单步通用撤销**覆盖任务 / 资料库记录 / 笔记 / 知识库文件（50 步历史、10 秒可见入口，2026-10-23；联动新任务不连带，长期记忆仍在账外）；**可解释仍缺** |
| 复核 | 看 AI 改了什么、跑到哪一步、确认或回滚 | 变更清单 + 一键撤销 + 动作留痕 + 运行态可见 | 部分：AI 回执条可撤销；Code 模式 `#agentDock` 的「进程」段以 2.5s 指纹轮询显示子代理状态 / 步数，另有技能 / MCP / 工作流段；**完整动作日志仍缺** |
| 沉淀 / 带走 | 导出 / 备份 / 同步 / 离线继续 / 把图存下来 | 一份可信的备份 + 明确的同步状态 | 备份 / 导出完整；画布文档 `wb_agent_diagrams` 已登记键注册表，随备份 / 导出 / 同步走；同步需自建服务 |

判定：**不属于这四步的功能，一律进 Labs（§6），不进主界面。**
补充判定：一个功能若**只在某个模式里成立**，先证明它是摆法差异而不是能力门禁，否则不做。

## 5. 信息架构：三模式，不再是三区

> **口径变更（2026-11-07）**：旧稿的「Today / Work / Assistant 三区」是 2026-10-20 的布局描述，
> 已被 v3.7.153 的三模式取代。Today 不再是并列的信息架构层，它是 **Work 模式里的一个视图**；
> Assistant 不再是独立一区，它是**三模式共用的贴底对话坞**（`docs/user-manual.md:152` 早已按此口径写给最终用户）。
> 三区说法只保留在历史快照里，不再作为设计依据。

### 5.1 模式布局契约

| | **Work** | **Code** | **Design** |
|---|---|---|---|
| 壳 | `.body`（默认） | `.body.code-mode`（grid `240px / 1fr / 300px`） | `.body.design-mode`（grid，同上） |
| 左 | `#side` 场景导航 | `#side` + `#sessionDock` 会话停靠（新建 / 切换；重命名删除仍在设置，不做第二套 CRUD） | `#side` + `#diagramDock` 图列表（新建 / 打开 / 删除） |
| 中 | `.main` 任务 / 看板 / 日历 / 资料库 / 笔记 + `.chat-panel` 贴底对话坞 | `.main-wrap` 全高对话区，输入行贴底居中；`.toolbar-row` 隐藏 | `#drawStage` 画布编辑器（形状 / 连线 / 文字 / undo-redo / 缩放 / 导出）；`.main` 与 `.chat-panel` 隐藏，画布占中栏 |
| 右 | `.task-rail`（今日 / Agent / 文件三页） | `.task-rail` + `#agentDock`（进程 / 技能 / MCP / 工作流，2.5s 指纹轮询）；**Agent tab 隐藏**——同一批数据的静态副本不重复列 | `.task-rail` + 对话坞轨道；AI 产物卡「在画布打开」把 `draw_svg` 结果作为底稿嵌入当前图 |
| 数据 | 同一份 | 同一份 | 同一份 |
| 适合 | 日常任务、资料、办公 | 写代码、看子代理跑到第几步 | 画流程图 / 架构图，继续加工 AI 产物 |

**模式状态**：持久化在 `wb_agent_uimode`（`work|code|design`，默认 `work`）；入口**只有左轨一个**
（左轨顶 `#uiModePill` 胶囊分段开关：当前段高亮、点段即切；2026-11-11 布局批L Move A 自顶栏搬入），
`toggleUIMode()` 仍支持循环切换。≤767px 左轨整体隐藏 ⇒ 移动端无模式切换入口（布局批L O1 裁决接受的移动代价），模式停留在当前值。
`applyUIMode()` 幂等；切换时必须清理互斥 dock、清掉 Code 模式的轮询定时器，且**不得改动任何业务数据**。

### 5.2 断点与不可用模式（诚实条款的落点）

| 宽度 | Work | Code | Design |
|---|---|---|---|
| **≥1024** | 三栏（左导航 / 主列 / 今日任务轨 280px） | ✅ 可用（三栏成立） | ✅ 三栏（画布居中） |
| **768–1023** | 左导航 / 主列，任务轨移出视口由顶栏「今日」滑出 | ⛔ **禁用**：菜单项 disabled + `setUIMode()` 二次拦截 + toast 说明原因（三栏需宽屏），不做安慰剂 | ✅ 单栏画布：**#110 方案乙**——`#side` 收起、`#mobBar` 底栏顶上，画布拿回整块高度（实测 `svgH 0 → 792`） |
| **≤767** | 底栏 4 组 + 侧栏抽屉 | ⛔ 禁用，同上 | ✅ 单栏画布，图列表收起，手机也能画 |

硬约束：**断点只用于布局变化，不用于隐藏功能差异**（`DESIGN-SYSTEM.md §2`）；模式不可用必须**给出理由**，
不许"点了没反应"；不得新增断点值（主档 `1440/1024/768`，细分档 `600/520/479/359`）。

### 5.3 导航硬约束

- 主路径层级 **≤3**；同一能力**只保留一个主入口**（其余入口只能作为上下文快捷方式）。
  Code 模式里 Agent tab 与 `#agentDock` 撞车时的处置已有先例（P2-5：隐藏静态副本，只留活数据 dock）。
- **AI 入口收敛到 2 处**：三模式共用的贴底对话坞 + 命令面板 `>`。
  AI 产物卡上的「在画布打开」是**产物级快捷方式**，不算第三个 AI 入口。
- **模式切换入口只有 1 处**：左轨顶 `#uiModePill` 胶囊分段开关（≤767px 随左轨隐藏，移动端无入口——O1 裁决口径）。
- 设置是能力的**唯一配置面**（MCP 发现 / 勾选 / 状态只在设置 → 扩展；技能在设置 → AI → 扩展），
  右栏轨道不重复列清单，避免两份清单漂移。

## 6. 功能分层

| 层 | 含义 | 例子 |
|---|---|---|
| **核心** | 服务闭环，必须有、必须好用 | 任务 CRUD / 看板 / 日历、资料库、**29 工具与计划-执行 / 子代理**、**会话**、**三模式**、**画布与 SVG/PNG 导出**、撤销、备份导出、离线 |
| **增强** | 核心的延伸，默认开启或显式开启，不占主路径 | RAG / 笔记、统计报表、自定义仪表盘、ICS / WebDAV、MCP / 技能、通知与定时提醒、云同步 |
| **Labs** | 有价值但不在闭环上，默认收起、标注实验性 | 工具箱非高频卡片、甘特 / 思维导图、萌宠、番茄钟 |
| **不做** | 见 §3 | 协作、企业、多文件、IDE、绘图平台、模式特供能力 |

> **漂移归位**：旧稿把「自定义仪表盘」列进 Labs，而 `docs/product-scope.md:33` 明写它是**核心**（15 个可拖拽组件）。
> 本次按能力清单归位到核心；`(增强/核心)` 的边界本就不该由两份活文档各写一套。

**诚实条款**（任何新功能上线前逐条过）：

1. 未完成或演示性质的能力，必须在 UI 上标注（示例数据 / 需自建服务 / 未接入），不得用"预告""即将上线"长期占位；`mock` 数据不得以产品能力口吻呈现。
2. **模式不可用必须说明原因**（窄屏 Code）；能力不可用也必须说明（MCP 未勾选、工具被白名单剥离、未配 Key 时拒发）。
3. **不把"工程侧已实现"写成"已真机验收"**：云同步增量上传、Electron 下载、PNG 导出成功支、Jira 真机这几笔账，
   在台账里必须保留"待验"状态，文案不得预支结论。
4. 演示级能力不进主界面；假数据、假连接、假集成只允许出现在 Labs 且带标记。

## 7. 设计原则（UI 与交互裁决用）

1. **行动优先于报表**：首屏第一眼是"能做什么"，不是"已经怎样"。
2. **默认本地、联网显式**：任何出网动作要么由用户点击触发，要么在设置里明确开关。
3. **AI 的改动可见、可撤销、可解释**：没有 undo 的写操作不允许上线。
   现状：单步通用撤销覆盖任务（创建 / 更新 / 完成 / 删除）、资料库记录、笔记、知识库文件（导入 / 同名替换 / 删除，含手工改动），
   50 步历史 + 10 秒可见入口；不做无限栈 / 跨设备撤销，联动新任务不连带；长期记忆仍在账外。
4. **演示级能力不进主界面**（见 §6 诚实条款）。
5. **模式只改布局，不改数据与权限**：切换模式不得产生业务写入、不得改变工具白名单、不得改变撤销栈。
6. **同一份数据只有一个写入口**：会话管理、任务 CRUD、图列表各自只保留一套主入口（其余是快捷方式）。
7. **不可用要给理由**：禁用、降级、失败都要有用户可见的说明与诊断留痕，不许静默。
8. **诚实优先于好看**：进度用真读数（流式字数 / 工具批次 N÷总数 / 计划步数），总数未知走不确定态，
   绝不做假百分比；没样本就写"还没有样本"，不渲染 `0ms`。

## 8. 指标（北极星 + 护栏）

- **北极星**：每周"完成闭环"的用户数——同一周内至少一次 捕获 → 委派与执行 → 复核 的完整动作；
  **按模式分列**，避免只看总数掩盖某个模式根本没人用。
- **过程**：首次成功任务时间、AI 动作成功率、子代理完成率与平均步数、撤销率、画布导出成功率、
  **模式渗透**（三模式周活分布）、**切换后 5 分钟内是否真的完成了一次动作**（切了不用＝摆法没兑现）。
- **护栏**（必须为 0 的几项）：模式切换导致的数据丢失事件、静默失败率、死入口数、
  **窄屏禁用模式"点了没反应"的投诉 / 断言失败**、同一能力主入口数超过 1、
  把演示态 / 未验收能力当成真能力的误判数。
- **效率护栏**：包体与首屏时间、数据丢失事件数（必须为 0）。

## 9. 版本与文档纪律

- 版本号唯一真相源 = `AGENTS.md §二` 登记表 + `package.json`；注释里不得写未登记的号。
- 本文件**每季度、或每次模式语义变更后**复核一次（2026-11-07 这次就是拖了 18 天才改，故加后一个触发条件）。
- 改动前按 **R13** 跑 `claim-check` 并认领，按 **R10** 在 `docs/agent-board.md` 声明一行；
  板面只记**意图与占用**，不记事实——版本是否发布、测试是否绿，一律以 `git log` / CI 结论为准，
  **不往板面写结论**（旧稿「留一条事实通告」与现行板面铁律冲突，本次订正）。
- 引用现状请读代码 / 跑门禁；`roadmap-2026Q4.md` / `iteration-plan.md` / `evaluation-*` 属历史快照，
  不作现状依据（`docs/README.md` 判读规则第 4 条）。
- 与 `docs/README.md` 的三级判读规则保持一致：本文件排第 1 级，结构 / 视觉契约排第 2 级。
