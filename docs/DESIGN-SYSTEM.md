# DESIGN-SYSTEM.md · 视觉与交互契约（活文档）

> 状态：**活文档（2026-10-20 起）**。本文件规定**必须遵守的设计契约**；
> `docs/ui-standards.md` 保留为实现细节与历史说明。冲突时以本文件为准。
> 已有门禁：`lint-tokens` / `lint-css-structure` / `lint-breakpoints` / 三态渲染测试 / 元素级溢出 e2e。

## 1. 令牌（tokens）

- 所有颜色、间距、圆角、阴影、层级**只能**来自 CSS 变量；`src/*.js` 里禁止新增硬编码色值
  （现存 332 处是债务，按"改到哪清到哪"处理，优先 `render-widgets.js` 的侧栏 6 色）。
- 间距阶：4px 基线（4/8/12/16/20/24/32/40/48/64），不得出现 5/7/9/13 这类奇数裸值。
- 圆角：6 档（2/4/6/8/12/16）；控件与卡片不得自造新圆角。
- 字号阶：12/13/14/16/18/20/24/28/32；**正文最小 12px**，9–11px 只允许出现在纯装饰徽标上且必须可读（对比度 ≥4.5:1）。
- 层级：`--z-*` 六档（base/raised/sticky/overlay/modal/toast），新浮层必须选一档，不得写裸 z-index。

## 2. 断点

以 `scripts/lint-breakpoints.mjs` 的允许集为准（当前：主档 `1440/1439`、`1024/1023`、`768/767`；
细分档 `600/520/479/359`）。**不得新增断点值**；长期目标是收敛，但收敛必须同时改守卫与债务清单，
不允许"先写一个新值再说过渡"。

- 桌面 ≥1024、平板 768–1023、手机 ≤767 三档行为必须各自定义完整。
- 断点只用于**布局变化**，不用于隐藏功能差异（功能差异用能力检测）。

## 3. 控件尺寸与触控

- 三档高度：**28（sm）/ 36（默认）/ 44（触控/主操作）**；不得出现 26/30/48 等新值。
- 粗指针（触屏）下所有可点区域 ≥44×44，含图标按钮；顶栏图标按钮在小屏不得小于 40。
- 主操作按钮在同一视图内**只允许一个**（视觉主色），其余用次色。

## 4. 浮层（Modal / Drawer / Sheet）

- 只允许三类：`Modal`（居中、阻断）、`Drawer`（侧边、设置/详情）、`Sheet`（底部、移动端选择）。
  不再新增第四种形态；现有 7 种逐步归并。
- 每个浮层必须：`role="dialog"` + `aria-modal="true"` + 标题关联；**Esc 关闭**；
  **焦点陷阱**（打开时聚焦首个可操作元素，关闭时焦点归还触发元素）；点遮罩关闭（确认类除外）。
- 同一时刻最多一层浮层（Sheet 覆盖在 Modal 上必须显式允许）。

## 5. 状态

| 状态 | 规范 | 入口 |
|---|---|---|
| 空 | 必须给"下一步动作"，不能只写"暂无数据" | `renderEmpty(scene)`（已登记 key 才能渲染） |
| 加载 | 所有 >200ms 的异步按钮必须进入 busy/禁用态 | `withLoading(btn, promise)` |
| 错误 | 必须说明**发生了什么 + 下一步**，不得静默 | `renderErrorState` / `toast(..., "error")` |
| 成功 | 轻量 toast，不阻断 | `toast(..., "ok")` |

- toast 四类（ok/warn/error/info）必须有独立视觉（当前 error/info 无样式，属缺陷）。
- 禁止"点击后无任何反馈"：无反馈即视为未接线。

## 6. 危险操作确认

- 唯一入口：`openConfirmModal({ title, body, danger, onConfirm })`；**禁止新增原生 `confirm()`**
  （现存 39 处逐步迁移，触达即改）。
- 删除、清空、覆盖导入、断开集成、退出登录必须二次确认；确认按钮文案用动词（"删除"），不用"确定"。

## 7. i18n

- 新增文案必须同时加 `zh`/`en` 两个键；禁止只写中文默认值。
- JS 中的 `t(key, "中文兜底")` 允许保留，但 key 必须真实存在；硬编码中文只允许在注释与示例里。
- 用户数据、错误原文不进翻译层。

## 8. 可访问性

- 所有交互控件必须有无障碍名（文本或 `aria-label`）；纯图标按钮必须有 `aria-label`。
- 禁止正 `tabindex`；焦点样式统一 `:focus-visible`，不得 `outline:none` 后不补。
- 文本对比度：正文 ≥4.5:1，次级文本 ≥3:1（9–11px 文本按正文要求）。

## 9. 提交前检查清单

1. 新增颜色/间距是否走了令牌？2. 是否引入新断点？3. 按钮高度是否在三档内？
4. 异步是否有 busy 态？5. 空/错状态是否可见？6. 危险操作是否走确认组件？
7. 新增文案是否双语？8. 新浮层是否有 Esc + 焦点陷阱？
