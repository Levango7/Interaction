🔒 安全说明：Key 经 AES-GCM 加密存于本机，密钥与密文同在浏览器存储内——可防随意窥视，但无法抵御能读取本机数据的攻击（非端到端安全）。请勿在共用/不可信设备上保存 Key。

可新增自定义场景，或为内置场景改名 / 换色。场景下有任务时不可删除（防止数据丢失）。改动保存后，侧栏、命令面板、统计与习惯链自动生效。

源场景任务完成时，按规则跨场景自动生成奖励/后续任务（生成的任务带「联动」标签）。点击关键词或目标场景可 inline 编辑。

一键导入预置任务集（考研复习 / 健身计划 / 编程学习 / 项目管理 / 习惯养成），到期日按今天 + 偏移自动计算。

启用插件可扩展自定义场景、卡片与习惯链规则。插件状态持久化到本地，启用/禁用即时生效。

每次数据变动后自动快照到本地（独立于「导出 JSON 备份」）。如手动导出前数据损坏，可从此处还原最近一次快照。

创建自定义主题（调整令牌色值），或为每个场景独立配色。主题可导出为 JSON 分享给其他用户。

开启后，助手具备中短期记忆（自动注入对话上下文）与多步目标规划能力（plan→逐步执行→complete_goal），对话循环上限由 6 轮放宽至 12 轮以支撑自主多步任务。可对我说「记住：xxx」直接写入记忆。

兼容 OpenAI 接口格式（OpenAI / DeepSeek / 通义 / 豆包 等均可）。Key 仅存本机浏览器。启用后，每个场景的 AI 助手可调用工具：创建/修改/删除任务、查询/完成任务、搜索、添加资料、查看总览、导出——你说的指令会真正落到工作台数据里。开启 Agent 模式后还可：remember/recall/forget 工作记忆、plan/complete_step/complete_goal 多步目标编排、list_records 跨场景查资料。

跨域提示：从本地文件直接调用可能被浏览器 CORS 拦截。最稳妥是用「启动本地服务.bat」以 http://localhost 方式打开，再启用 AI。
