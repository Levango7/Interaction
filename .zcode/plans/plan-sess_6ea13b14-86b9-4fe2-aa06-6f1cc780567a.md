**② i18n 最小化接入（英语语言模式）**
i18n 模块已在（行 18217-18704），未充分发挥作用。最小化接入方案：

**Step 1**：设置页加入语言切换器（select：中文/English，调用 `setLang()`，设置 localStorage 持久化）  
**Step 2**：为 `<html lang="...">` 属性动态设置 `document.documentElement.lang`（`initI18n()` 启动时根据 localStorage 读值）  
**Step 3**：为所有 `[data-i18n]` 节点补全 key（约 50-80 个主要 UI 标签/按钮/状态词），确保 `applyI18n()` 能替换  
**Step 4**：在 toast 消息、confirm 对话框中引入 `t()` 包装（约 40 条消息）  
**Step 5**：`MESSAGES` 字典已有英文翻译，切换时自动回退

**不涉及**：AI 系统提示词、人工撰写内容、AI 教练文案（保留中文）

**③ 六大场景记录表单整洁化**
策略：为每场景 record 表单字段增加宽度分级 `.fld-*` 类，同时对 `code`/`design`/`life` 等业务强场景增强字段语义。

| 场景 | 字段 | 宽度类 | 变化 |
|------|------|--------|------|
| office | title（会议主题） | `.fld-lg` | 加宽到 480px |
| office | who（参会人） | `.fld-md` | 160px |
| data | type（类型 select） | `.fld-md` | 160px |
| data | title（标题） | `.fld-lg` | 480px |
| design | type（类型 select） | `.fld-md` | 160px |
| design | title（作品名） | `.fld-lg` | 480px |
| study | title（主题） | `.fld-lg` | 480px（弱化 type/status 字段宽度） |
| code | lang（语言） | `.fld-sm` | 120px（语言名短） |
| code | title（标题） | `.fld-lg` | 480px |
| life | type（类型 select） | `.fld-md` | 160px |
| life | value（数值） | `.fld-sm` | 120px（数值短） |

同时统一表单按钮布局：所有 record 表单 `addbtn` 改为 `<div class="fld fld-sm">` 包裹以保证底对齐一致性。
