# 图标去重合理化 + 输入框/按钮布局规范化（v2.1.1）

## 问题盘点（双审计 + 复核结论）

### 图标系统
- **字形不一致**：关闭钮 `✕`(U+2715) 与 `×`(U+00D7) 并存 13 处；警告 `⚠`/`⚠️` 双形态；展开箭头三套（▸▾ / ▶▼ / ▾▴）；习惯链状态 ⏸/~/✓/○ 混杂
- **重复定义**：约 15 组 SVG 跨字典/内联重复而未引用 `UI_ICONS`（chain/robot/puzzle/moon/sun/download/search/alert/check/book/gear/file 等）
- **死键**：`UI_ICONS` 的 lock/chartBar/brain/alert/file/clipboard/search/wave/book2 共 9 键无引用（去重后部分会复活）
- **模板 bug**：行 14728 `'...${ic("puzzle")}...'` 是单引号普通字符串，不插值，插件详情弹窗标题会原样显示字面文本
- **emoji 残留**：5 字符 9 处（⚠️×4、❌、☕、⏸）
- **语义过载**：`UI_ICONS.overview` 身兼主页/总览/数据卡/自定义场景兜底四职

### 布局
- **按钮高度阶梯混乱**：chat-attach 28px vs chat-send 32px；kbtns 32px vs todo-ops 28px；编辑弹窗取消(btn-ghost ~37px) vs 保存(addbtn 32px)
- **"添加"按钮族四种尺寸**：taskForm/recForm 裸 addbtn、scAddBtn .sm、chainAddBtn 内联 padding、闹钟 tbtn 改
- **checkbox 靠内联 width:auto**：10+ 处，应 CSS 层统一
- **移动端溢出**：alarm-form 无 flex-wrap；form-row 移动端 column 与内联 max-width 冲突；断点 720 vs 767 不一
- **令牌卫生**：`--radius-full` 未定义但 4 处用回退兜底；`.input` 类死规范；pomo-actions 与 tracker-actions 完全重复

## 实施步骤

### 1. 图标字形统一
- 关闭钮统一 `✕`，替换 5 处 `×`（行 7864/8660/10151/13882/13941）
- 警告统一 `⚠️`（带 FE0F），替换 3 处 `⚠`（行 3127/6662/14275）
- 展开箭头统一 `▸`/`▾`，替换 `▶`/`▼`/`▴`
- 习惯链状态 ⏸/~/✓/○ → 统一符号集
- 残留 emoji（❌/☕）→ 文本或 SVG

### 2. 图标字典去重
- `SIDE_MENU_ICONS` 的 plugin/ai/chain/look/doc 改为引用 `UI_ICONS`（5/7 重复）
- `TOAST_ICONS` 的 warn/ok/error 引用 `UI_ICONS`（error 与 danger 本就相同）
- `EMPTY_ICONS.no-search` 引用 `UI_ICONS.search`
- 去重后重估并删除真死键
- 修复行 14728 模板 bug（单引号 → 反引号）

### 3. 图标语义合理化 + 规则
- 拆分 `overview` 过载：自定义场景兜底改用独立图标
- 评估"统计"三图标（stats/chartBar/dash）是否收敛
- design-ui-guidelines.md 增补图标规则章

### 4. 按钮高度阶梯
- 定义层级：图标钮 32×32 / 小操作钮 min-height 32px / 中钮 36px / 主钮 40px / 移动触摸 44px
- chat-attach 28→32；kbtns 与 todo-ops 统一 32px
- 修编辑弹窗取消/保存高度差；统一"添加"按钮族

### 5. 输入框布局统一
- CSS 层加 `input[type="checkbox"]{width:auto}`，删 10+ 处内联
- 加 `.color-input` 类替换内联 width:44px
- 定义 `.fld-sm/md/lg` 宽度工具类，替换 form-row 内联 max-width

### 6. 移动端修复
- alarm-form 加 flex-wrap + ≤767px 降级
- 修 form-row 移动端内联 max-width 冲突
- 断点统一 720→767；补 `--radius-full` 令牌

### 7. 令牌卫生
- 合并 pomo-actions/tracker-actions；处理 `.input` 死类；收敛硬编码 px

### 8. 规则固化
- design-ui-guidelines.md 增"图标设计规则"+"按钮/输入框布局规则"两章
- ui-standards.md 同步

## 验证
lint-colors + lint-tokens + vitest 全绿；Playwright 实测桌面图标/按钮高度/输入对齐、移动端 alarm-form 与 form-row 无溢出；逐页核对图标无重复冲突。

## 风险
- SIDE_MENU_ICONS 改引用需确认所有读取点兼容（均为只读取值，风险低）
- 按钮高度变化影响多页视觉，需 Playwright 逐页截图比对
- 断点统一 720→767 影响 721~767px 小平板，需实测该区间
